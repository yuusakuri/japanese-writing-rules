# Register Writing Rule

## 指摘の反映手順

1. 指摘された文章を読み、対象文書の意味と文脈を保って自然な日本語へ修正する。
2. `japanese-technical-business-writing`のSkill、専門用語辞書、Lintを確認し、既存規則との重複を避ける。
3. 同じ問題が別の技術書やビジネス文書でも発生するかを判断する。
4. 再利用できる指摘を、判断の性質に合う場所へ反映する。
5. Lintを追加または編集した場合は、正常例と違反例の両方をテストする。
6. `test/corpus/natural`の文書へstrict Lintを実行し、正常な文章を新しく誤検知しないことを確認する。
7. 反映後の規則が正常な文章を不自然にしないことを確認する。

## 反映先の判断

正式名称、大文字と小文字、専門用語の表記など、文脈によらず一つの表記へ確定できる指摘は`terminology.yml`へ登録する。

文章の意味や文脈を理解して判断する必要がある指摘は`SKILL.md`へ反映する。
不要な否定対比、曖昧な評価語、主語不足、比喩、体言止めの不自然さは、単語を禁止するLintへ変換しない。

文章構造だけから高い精度で判定でき、既存Lintで検出できない問題が繰り返し発生する場合だけ独自Lintを作る。
独自Lintを作る場合は、違反例だけでなく、似た構造を持つ自然な文章もコーパスへ登録する。

一度限りの好みや、特定文書だけで成立する指摘は再利用する規則へ登録しない。

## 規則の作り方

専門用語を日本語化すること自体を改善とみなさない。
正式名称または技術分野で一般的な表記を優先する。

検出された語を別の語へ置き換えるだけの修正方法を登録しない。
文章が不自然になる原因を一般化し、文全体をどのように組み直すかが分かる規則にする。

規則によって正常な文章まで不自然になる場合は、その規則を削除するか、適用範囲を狭める。
最終的な基準はLintの検出件数ではなく、自然で正確な日本語の技術書やビジネス文書になっていることとする。
